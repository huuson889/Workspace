# Workspace development rules

- This root is a GitHub-backed sparse working copy of `huuson889/Workspace`.
- Read `GITHUB-WORKSPACE.md` before modifying checkout layout or packaging.
- Application rules remain in `Keepit-OCR/AGENTS.md`; read `Keepit-OCR/manifest.json` for the current application version.
- Missing `Keepit-OCR/vendor/` and `Keep-it/` are intentional local omissions, NOT remote deletions.
- Run `python tools/workspace.py hydrate ocr-assets` before extension tests/packaging. Thin source alone is not runnable.
- To consult the original source, run `python tools/workspace.py hydrate original`; evict only after verifying no changes.
- Never replace local OCR model/runtime paths with GitHub URLs: delivered extensions must remain offline-capable.
- Never stage sparse omissions as deletions or force-push. If cache metadata disappeared, run `python tools/workspace.py bootstrap`, inspect status and hydrate as needed.
- Save changes to GitHub before relying on cache eviction. `~/.cache` is transient, not a backup.
- Private SSH keys remain outside Workspace, never in commits, ZIPs, logs or chat. SSH deploy keys do not grant GitHub Releases API access.
- Keep app-specific historical source restrictions and user instructions unchanged. Repository storage work does not authorize app redesign or engine changes.
- OCR responsive demos must follow the current Documents viewer responsive shell and retain Keepit's actual control designs/renderers on every screen; adapt dimensions and scrolling only. The page-list sheet is explicitly approved. Language selection must use the app's stacked `kpick` list, native/translated names, checkboxes and search behavior, never custom chips.
- OCR demo portrait sheets must sit flush left/right/bottom and share Keepit's glass tokens, sheet motion and `LHN_SHEET` gestures through one presentation adapter, not per-sheet lookalikes. Sheet drop shadows are off. Scrims dim without backdrop blur so the scaled viewer paints normally. Page-number pickers must reuse the actual Keepit list component (`LHN_ICONS.createFlowSelect`) with a centered numeric editing face (direct typing plus quick list), responsive sizing and scroll-boundary adaptations: OCR range endpoints are 112px when space permits and shrink equally on smaller screens, without the old numeric-input focus wrapper. OCR range endpoints stay enabled in every scope; focusing, typing or opening either quick list automatically selects the range scope, with no prerequisite radio click. An unchanged blur must not override a subsequent scope choice. OCR output/resolution fields use that same list component, without numeric editing, and always open below their trigger (scroll/constrain the form rather than flipping these lists upward). Remove the extra demo-only OCR action group from More on every viewport. The single OCR tool itself belongs immediately after Ask AI in the real tools dock; keep it neutral when closed and move that same node into the ordinary More tools slot when space is short, restoring it when space returns. Do not pin it separately, duplicate it or reintroduce the removed result/region/progress shortcuts. Portrait inner cards use translucent Keepit tile/line tokens, not opaque black blocks. Keep mouse sheet close poses until the closed state has painted; use frame-synchronized motion and preserve the unmodified shared touch engine. Standalone demos embed these authentic sources inline for offline use; later app integration must reference the shared modules. The demo's Main menu button deliberately opens nothing; do not change the real Keepit menu. Retain the complete Keepit Engine options section after file output, including PDF resolution, threads, Fusor model folder/status, method and guidance. Preserve current engine availability: Tesseract only; PP-OCR/Fusor settings and their unavailable switches remain visible but disabled, not omitted or falsely enabled.

- OCR demo surfaces use the actual Keepit Settings material roles in both orientations: shared theme glass/blur/tile tokens, Settings field/popover/hover roles, and a single isolated ::before glass backing (root and structural children stay transparent), with no sheet shadows or blurred scrims. Use Settings dimming (.4 portrait / .16 landscape). Avoid stacking white tile films on containers and their rows, opaque Cancel/editor backgrounds or old opaque picker selection fills. Check effective computed styles of inputs, nested editors, Cancel, popovers and selected rows, not only token declarations. The OCR toolbar button must not have an ID-specific face/alignment override; native vbtn/moreTools styles own its layout. Every portrait sheet uses the same Keepit `.grip` geometry: 40×4px, 2px radius, rgba(148,163,184,.55), 10px top/bottom space including the native panel's top padding, plus its expanded hit area. Remove per-sheet decorative bars. Resting sheets/dialogs must not retain unnecessary transforms or permanent will-change layers; retain shared open/close motion and gestures. End missed mouse releases/lost pointer capture/window blur before a later hover can continue a stale drag. Check actual browser hover over all sheet types, not synthetic pointer events alone.

- Standalone OCR demos must include Keepit's native OCR notice card and bulb on every viewport, fitted to the document area. Keep collapse/reopen, ten-second auto-collapse, interaction hold, Don't show again, and OCR-entry actions; a narrow area's collapsed bulb must still open its card when clicked. Scope demo preferences to the sample and clearly label the blank viewer/simulated result; do not imply a real file was inspected or recognized. Notice materials follow the same Settings roles as the other demo surfaces.

- User packaging rule: always commit and push ZIP deliverables to the matching GitHub folder `<source-folder>-Zip` on `main` (e.g. `Keepit-OCR/` → `Keepit-OCR-Zip/`). Cache-only links and GitHub Releases are not substitutes. Preserve versioned names; never overwrite an existing ZIP.
- ZIP folders are omitted by the default thin checkout. Stage newly produced packages explicitly with `git add --sparse Keepit-OCR-Zip/<filename>`, commit and push; verify the remote blob before any local eviction. Do not regenerate deleted older ZIPs.
