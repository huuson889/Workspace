# Keepit — File labels demo v5

Bản HTML demo loại tệp v5 được giữ lại trong cache dưới tên `labels623-demo.html` và khôi phục nguyên byte vào GitHub sau khi bản HTML ở thư mục gốc Arena bị xoá nhầm trước khi push.

- Nội dung tự ghi `HTML demo · v5`; PDF glyph thu88%, icon Ảnh option2.
- Bản khôi phục:20.807byte; chưa có hash bản gốc đã xoá để chứng minh độc lập rằng hai bản khớp từng byte.
- Không dựng lại hoặc tái thiết kế giao diện. Không thay mã nguồn app.
- ZIP chứa HTML và README này.

Quy tắc bàn giao demo: luôn commit/push HTML và tài nguyên cần thiết vào `Keepit-Demo`, ZIP vào `Keepit-Demo-Zip`, xác minh từng file trên GitHub trước khi xoá bất kỳ bản local nào. Không suy từ một demo đã push ra toàn bộ demo đã push.
