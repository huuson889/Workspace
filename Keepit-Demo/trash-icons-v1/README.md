# Keepit — Trash icons demo v1

Open `keepit-trash-icons-demo-v1.html` directly in a browser. Single offline HTML, all SVG/CSS/JS inline, no dependency or external request.

This is a design demo only. Keepit-OCR remains the approved3.5.632; no extension source, manifest, storage, import/drag, trash restore/delete or actual user data is changed.

## Options

- A (recommended): filled recognizable globe, note page, headphones and microphone.
- B: consistent folded-file silhouette with white type marks for all four.
- Existing PDF/Word/PowerPoint/Image SVG paths copied verbatim from `Keepit-OCR/js/shared/icons.js` including88% PDF lettering and approved picture icon; unaffected by A/B selection.

Controls: switch A/B, light/dark,18/22/28px row icon sizes; inspect a row's vector and scale samples; demo selection checkboxes. Trash list is fixed example data. Speaking is a visual concept only, not an implemented extension feature.
